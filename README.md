# 碰碰岛 8.10.0 · 衣随势动

六名伙伴原先缺少衣发跟随与正面转身过渡，换向时会直接翻面。本版为每人增加12张选用绘画，单人图集从16帧扩为28帧，共新增72张，保持原有弹射闯关。

- 衣袖、发梢、发辫、冠羽和腰带增加待机变化与收招余势；按角色体重保留不同动作节奏。
- 转身经右斜面、近正面、正面及左侧过渡，转向由瞄准驱动。反弹与被撞飞不触发乱翻面。
- 快速松手使用短转身衔接；转到一半被击中时按当前可见方向受击。暂停冻结动作，减少动态效果设置保留必要攻击姿势。
- 新旧素材按脚底和角色比例校准，保持原始宽高比。试招展示完整转身、出手和受击循环。

100项回归检查、六角色试招、四种浏览器尺寸的触控/暂停/音乐检查通过。Android 15安装与8.9升级检查见本版本CI。

本版仍是有限帧二维插画动画。左侧过渡使用正面桥接加镜像，并非完整侧后方向原画或逐束发丝骨骼。实体手机的触觉、温度与长时间帧率尚未验收。
