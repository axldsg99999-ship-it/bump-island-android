# 碰碰岛 8.7.0 · 借草藏锋

沿用单人弹射闯关，增加可读、可预测的地形战术。

- **草丛隐蔽**：进入草丛停稳后隐蔽。己方显示淡化轮廓和“潜伏”，敌方隐藏人物、脚下标记、血条及预瞄中的目标身份。敌人靠近1.35场景单位以内可以察觉。草丛不阻挡真实碰撞或范围伤害。
- **显形规则**：从草中出手或受伤后，至下次己方回合才能恢复隐蔽。普通弹射进入草丛、停稳且未受伤可以直接潜伏。敌人失去可见目标后，按草丛位置探查，不读取隐藏角色的精确位置。敌人蓄势时会现身，保留已获得的一次伏击机会。
- **伏击与背袭**：潜伏发起的首个敌对碰撞增加25%基础碰撞伤害；撞中目标背面120度范围增加35%，同次出手对同一目标只奖励一次背袭。两者叠加上限60%。技能附伤不再次乘算，护甲也不会因一次碰撞重复扣层。
- **朝向可读**：脚边墨尖表示面朝方向，仅主动出手改变朝向，被推撞和撞墙不转向。预瞄提示预计伏击／背袭，实际命中有对应伤害文字与朱墨击痕。
- **多次破障**：新增两撞竹障、三撞石垒。有效撞击法向速度至少2.2；擦碰和贴住后的连续物理计算不重复计数。旧陶罐、竹栅、残柱保留材质耐久规则。裂纹、刻痕、预瞄剩余次数和最后一撞的破断提示与实际状态一致。
- **场景布置**：花园11处、竹林12处、海台10处、雪境10处交互地形。草丛与坚固障碍分布于侧翼，保留中路和借壁路线。破坏状态跨波次保留，新对局重置。
- **统一资源**：新增竹障／石垒及对应残骸使用同一墨线矿物色体系，透明素材包含在APK；本轮也纳入上一轮本地开发版的四种新场景、受击方向反馈和角色投影。

## 验收边界

77项Node回归覆盖隐蔽、察觉、显形、敌人重选目标、未知目标不泄露、伏击背袭、护甲、接触去重、预瞄／实际碰撞一致及旧玩法。手机浏览器检查实际触控、取消、破障、暂停、音乐和四种尺寸。独立布置的战术检验画面使用生产引擎，不能冒充自然流程录屏。安卓安装、升级和离线检查的结果单独记录；未做实体手机主观手感验收。
